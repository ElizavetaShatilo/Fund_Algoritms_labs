Длина строки:
./cmake-build-debug/task1 -l hello
Ожидается:
Длина строки: 5

Реверс:
./cmake-build-debug/task1 -r hello
Ожидается:
Результат: olleh

Реверс одной буквы:
./cmake-build-debug/task1 -r a
Ожидается:
Результат: a

Верхний регистр на нечётных позициях:
./cmake-build-debug/task1 -u abcdefg
Ожидается:
Результат: aBcDeFg

Группировка символов:
./cmake-build-debug/task1 -n a1!b2?c3
Ожидается:
Результат: 123abc!?

Случайная конкатенация:
./cmake-build-debug/task1 -c ab 42 cd ef
Ожидается:
Результат: efabcd

Только одна строка для -c:
./cmake-build-debug/task1e -c abc 7
Ожидается:
Результат: abc

Неизвестный флаг:
./cmake-build-debug/task1 -x abc
Ожидается:
Ошибка: Неизвестный флаг (допустимы -l, -r, -u, -n, -c).

Флаг без дефиса:
./cmake-build-debug/task1 l abc
Ожидается:
Ошибка: Неизвестный флаг (допустимы -l, -r, -u, -n, -c).

Лишние аргументы для -l:
./cmake-build-debug/task1 -l a b
Ожидается:
Ошибка: Некорректный ввод аргументов.

-c без seed:
./cmake-build-debug/task1 -c abc
Ожидается:
Ошибка: Некорректный ввод аргументов.

Отрицательный seed:
./cmake-build-debug/task1 -c abc -5 x
Ожидается:
Ошибка: Некорректный ввод аргументов.

Нечисловой seed:
./cmake-build-debug/task1 -c abc 12a x
Ожидается:
Ошибка: Некорректный ввод аргументов.

Слишком мало аргументов:
./cmake-build-debug/task1 -r
Ожидается:
Использование: ... <флаг -l|-r|-u|-n|-c> <строка> [seed строки...]
Ошибка: Некорректный ввод аргументов.
